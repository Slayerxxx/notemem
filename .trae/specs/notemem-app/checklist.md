## 乐理核心逻辑正确性
- [ ] Checkpoint 4: C 大调音阶为 [C, D, E, F, G, A, B]，对应音级 I-VII 正确
- [ ] Checkpoint 5: A 大调音阶为 [A, B, C♯, D, E, F♯, G♯]（升号显示正确），F 大调为 [F, G, A, B♭, C, D, E]（降号显示正确）
- [ ] Checkpoint 6: 全部 12 大调（C, G, D, A, E, B, F♯, F, B♭, E♭, A♭, D♭）均可正确生成，升降号显示符合乐理规范
- [ ] Checkpoint 7: C 大三和弦组成音为 [C, E, G]，B♭ 大三和弦为 [B♭, D, F]，B 大三和弦为 [B, D♯, F♯]，音程正确（大三度 4 半音、纯五度 7 半音）
- [ ] Checkpoint 8: 难度配置正确：音级训练 L1-L12 对应 12 个大调（C、G、F、D、B♭、A、E♭、E、A♭、B、D♭、F♯），每个等级仅训练一个调；单题限时默认 15 秒，可在自定义模式中调整
- [ ] Checkpoint 9: 升号调（A, E, B, F♯ 等）显示升号音名，降号调（F, B♭, E♭, A♭, D♭ 等）显示降号音名，不使用等音替代

## 游戏循环与分数系统

- [ ] Checkpoint 21: 答错时正确答案高亮闪烁，用户选项变红，视觉反馈明确
