# NoteMem - 固定音名记忆训练应用 PRD

## Overview
- **Summary**: 基于 Vue 的移动端友好网页应用，帮助用户通过游戏化训练快速记忆音乐理论中的固定音名，包含两大核心模块：大调音级反应训练和和弦组成音训练。采用「单题限时 + 即时反馈 + 单调专注 + 错题强化」的训练模式，纯前端实现，数据本地持久化。
- **Purpose**: 解决音乐学习者记忆固定音名（音级关系、和弦组成）效率低的问题，通过单调专注、即时反馈、节奏自控的训练方式，让初学者有充足时间推算理解，逐步强化肌肉记忆，提升音乐理论反应速度。
- **Target Users**: 音乐初学者、乐理学习者、需要巩固固定音名基础的音乐从业者。

## Goals
- 实现大调音级反应训练：用户能快速判断指定大调中某个音名的音级（I-VII）
- 实现和弦组成音训练：用户能快速识别指定和弦（首期大三和弦）的组成音
- 构建完整游戏化机制：分数、连击、速度奖励、多种训练模式
- 建立本地数据体系：错题本、历史成绩统计、localStorage 持久化
- 移动端优先的响应式界面，PC 端可正常调试访问

## Non-Goals (Out of Scope)
- 不实现小调、七和弦等扩展调式/和弦（预留接口，但首期不开发）
- 不实现后端服务，所有数据本地存储
- 不实现用户账户系统、云同步功能
- 不实现社交分享、排行榜等功能
- 不实现音频播放/音高识别功能（仅文字音名训练）

## Background & Context
- 项目从 0 开始搭建，目前仅有设计方案文档，无任何代码
- 技术栈约束：Vue 框架（具体版本待定，推荐 Vue 3 + Vite）
- 纯前端实现，localStorage 作为数据存储层
- 核心设计原则：单调专注、强即时反馈、节奏由用户掌控（初学者可慢慢推算，熟练后自然提速）

## Functional Requirements
- **FR-1**: 模式选择页 - 提供两个训练入口（大调音级反应 / 和弦组成音训练），以及错题本、难度设置、统计等辅助功能入口
- **FR-2**: 大调音级训练 - 支持 L1-L12 共 12 个难度等级，每个等级专注训练一个大调（不混合多个调），按调的常用度排序（升降号越少越常用）：L1=C→L2=G→L3=F→L4=D→L5=B♭→L6=A→L7=E♭→L8=E→L9=A♭→L10=B→L11=D♭→L12=F♯，题目随机生成「当前调 + 音名 → 音级」
- **FR-3**: 和弦组成音训练 - 支持 L1-L3 三个难度等级，从 C/F/G 根音扩展到全部 12 根音的大三和弦，题目随机生成「和弦 → 组成音组合」
- **FR-4**: 统一训练页框架 - 题干区（调/和弦 + 问题）、选项区（音级按钮/和弦组合选项）、状态栏（分数、连击、剩余题数/倒计时）
- **FR-5**: 核心游戏循环 - 出题→展示→计时→作答→即时反馈（颜色/音效，显示正确答案与解析）→等待用户点击「下一题」→下一题。不自动跳转，给用户充足的推算与消化时间
- **FR-6**: 分数与连击系统 - 基础分10分，速度奖励（<50%时间+5分，<30%+10分），连击加成（5连+2，10连+5）
- **FR-7**: 多种训练模式 - 限时模式（1/3/5分钟）、题量模式（20/50/100题）、错题模式、自定义模式
- **FR-8**: 结果结算页 - 展示正确率、平均反应时长、错题数量、最快反应记录、本轮得分
- **FR-9**: 错题本 - 自动记录错题（调式+音级/和弦+错误选项），支持移除单题、清空全部，错题模式下优先从中出题
- **FR-10**: 本地统计 - 按难度维度存储历史最高分、平均正确率、平均反应时间
- **FR-11**: 难度设置 - 用户可手动选择当前训练难度等级（默认 L1）
- **FR-12**: 自定义模式配置 - 自由选择训练调式/和弦类型、题量、是否限时

## Non-Functional Requirements
- **NFR-1**: 移动端适配 - 界面在 iPhone SE (375px) 到主流旗舰机 (428px+) 宽度下均可用，按钮尺寸适配拇指点击（≥44px）
- **NFR-2**: 响应式 - PC 端浏览器访问时布局正常，最大宽度居中显示，不拉伸变形
- **NFR-3**: 性能 - 单题切换（反馈→下一题）流畅无卡顿，页面首屏加载时间 < 3s
- **NFR-4**: 数据持久化 - 刷新/关闭浏览器后错题本、历史统计、设置不丢失
- **NFR-5**: 可访问性 - 反馈除颜色外有文字/音效辅助，按钮有足够间距避免误触

## Constraints
- **Technical**: 
  - 必须使用 Vue 框架实现
  - 纯前端单页应用，无后端依赖
  - 存储仅使用 localStorage，不可引入 IndexedDB 等复杂方案
  - 移动端优先设计，PC 端兼容
- **Business**: 
  - 首期仅实现设计方案中明确列出的功能，小调/七和弦等后续扩展仅预留接口
- **Dependencies**: 
  - 构建工具：Vite（推荐）或 Vue CLI
  - 路由：Vue Router（页面切换）
  - 状态管理：Pinia 或 Vue Composition API + reactive（游戏状态共享）

## Assumptions
- 乐理规则严格按照方案执行：12 大调遵循「全全半全全全半」，升/降号调显示对应音名
- 和弦组成音首期仅覆盖大三和弦：根音 + 大三度(4半音) + 纯五度(7半音)
- 音效使用 Web Audio API 生成简单提示音，不引入外部音频资源文件
- 用户使用环境支持 localStorage（现代浏览器均支持）
- 作答后不自动跳转，由用户点击「下一题」按钮进入下一题，给初学者充足的推算与消化时间
- 单题限时设为较宽松的默认值（音级训练 15 秒），用户可在自定义模式中调整（3-30 秒），超时视为答错但仍需用户确认进入下一题

## Acceptance Criteria

### AC-1: 模式选择页入口
- **Given**: 用户首次打开应用
- **When**: 应用加载完成
- **Then**: 显示模式选择页，至少包含「大调音级反应训练」「和弦组成音训练」两个入口按钮，以及错题本、统计、设置入口
- **Verification**: `human-judgment`

### AC-2: 大调音级训练 - L1 题目生成正确性
- **Given**: 难度设为 L1 入门（仅 C 大调）
- **When**: 连续生成 20 道题
- **Then**: 所有题干的调式均为 C 大调，音名仅包含 C D E F G A B（无升降号），正确音级符合 C 大调音阶结构
- **Verification**: `programmatic`

### AC-3: 大调音级训练 - 各难度单调专注
- **Given**: 难度分别设为 L1 至 L12
- **When**: 生成足够多题目样本
- **Then**: 每个难度等级仅出现一个调：L1=C、L2=G、L3=F、L4=D、L5=B♭、L6=A、L7=E♭、L8=E、L9=A♭、L10=B、L11=D♭、L12=F♯；同一难度内绝不出现其他调；升降号数量随等级递增（0→6），符合「升降号越少越常用」的常用度排序
- **Verification**: `programmatic`

### AC-4: 和弦训练 - 大三和弦组成音正确性
- **Given**: 任意难度下的和弦训练
- **When**: 出现某根音的大三和弦题目（如 C 大三和弦）
- **Then**: 正确选项的组成音严格符合音程规则（C→C+E+G），升/降号显示正确（如 B♭→B♭+D+F）
- **Verification**: `programmatic`

### AC-5: 和弦训练 - 干扰项设计
- **Given**: 任意和弦题目
- **When**: 查看 4 个选项
- **Then**: 3 个干扰项各不相同，至少包含以下类型之一：相邻根音和弦、小三变体、音程错误组合，无完全重复选项
- **Verification**: `human-judgment`

### AC-6: 游戏循环 - 即时反馈与手动进入下一题
- **Given**: 训练进行中，单题已显示
- **When**: 用户点击任意选项（或单题超时）
- **Then**: 立即停止计时，正确选项变绿/错误变红并高亮正确答案，显示计时结果、得分变化以及音程关系解析；页面底部出现「下一题」按钮，需用户主动点击才进入下一题，不会自动跳转
- **Verification**: `human-judgment`

### AC-7: 分数系统 - 基础分与速度奖励计算
- **Given**: 单题限时 T 秒
- **When**: 用户答对，反应时间 t
- **Then**: 基础分 10 分；若 t < 0.3T 额外 +10 分；若 0.3T ≤ t < 0.5T 额外 +5 分；若 t ≥ 0.5T 无速度奖励
- **Verification**: `programmatic`

### AC-8: 连击系统 - 加成计算
- **Given**: 用户连续答对
- **When**: 累计 5 连 / 10 连
- **Then**: 第 5 连后的每题额外 +2 分，第 10 连后的每题额外 +5 分；答错后连击数清零
- **Verification**: `programmatic`

### AC-9: 训练模式 - 限时模式倒计时
- **Given**: 选择限时模式（如 1 分钟）
- **When**: 训练开始
- **Then**: 状态栏显示倒计时从 60 秒递减，时间归零后立即跳转结算页，不再生成新题
- **Verification**: `human-judgment`

### AC-10: 训练模式 - 题量模式计数
- **Given**: 选择题量模式（如 20 题）
- **When**: 训练开始
- **Then**: 状态栏显示已答/总题数进度，答完 20 题后立即跳转结算页
- **Verification**: `human-judgment`

### AC-11: 错题本 - 自动记录与移除
- **Given**: 用户答错题目
- **When**: 反馈完成
- **Then**: 该题（含调/和弦、题干、正确答案、用户错选）自动加入错题本；在错题本页面点击移除后该题消失
- **Verification**: `human-judgment`

### AC-12: 数据持久化 - localStorage
- **Given**: 用户已完成训练并产生错题、统计数据
- **When**: 刷新浏览器或关闭后重新打开
- **Then**: 错题本内容、历史统计数据、用户难度设置保持不变
- **Verification**: `human-judgment`

### AC-13: 结算页数据完整
- **Given**: 一轮训练（任意模式）结束
- **When**: 进入结算页
- **Then**: 显示本轮得分、正确率、平均反应时长、错题数量、最快反应记录，数据与实际训练过程一致
- **Verification**: `human-judgment`

### AC-14: 移动端响应式布局
- **Given**: 页面在 375px ~ 428px 宽度的移动端视口
- **When**: 查看训练页选项按钮
- **Then**: 音级训练 7 按钮均匀分布，和弦训练 4 选项竖向排列，按钮高度 ≥ 44px，间距充足，无水平滚动条
- **Verification**: `human-judgment`

### AC-15: 升降号音名显示规范
- **Given**: 题目涉及升号调（如 A、E、B 大调）或降号调（如 F、B♭、E♭ 大调）
- **When**: 显示题干音名或选项音名
- **Then**: 升号调显示升号音名（如 C♯、F♯），降号调显示降号音名（如 B♭、E♭），不使用等音替代（如 A 大调不显示 D♭ 替代 C♯）
- **Verification**: `programmatic`
